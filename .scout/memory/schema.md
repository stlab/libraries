# Entity Types

| Type | Description | Default Confidence | Default Tier | Decay Rate |
|------|-------------|-------------------|-------------|------------|
| observation | Raw finding from a session | 0.5 | working | 0.95/day |
| episode | Session summary, compressed from observations | 0.6 | episodes | 0.98/day |
| discovery | Verified insight about the codebase | 0.7 | knowledge | 0.995/day |
| decision | Architectural or design choice | 0.7 | knowledge | 0.995/day |
| pattern | Recurring code or process pattern | 0.8 | knowledge | 0.995/day |
| procedure | Step-by-step workflow | 0.8 | procedures | 0.999/day |
| person | Team member with role/expertise | 0.9 | peers | 0.999/day |
| project | Initiative or workstream | 0.7 | knowledge | 0.98/day |
| concept | Domain concept or term | 0.9 | knowledge | 0.999/day |

# Relationship Types

| Type | Meaning | Edge Category |
|------|---------|--------------|
| caused_by | X was caused by Y | import |
| supersedes | X replaces Y (target confidence drops) | import |
| contradicts | X conflicts with Y (flagged for resolution) | import |
| applies_to | X is relevant to Y | call |
| owned_by | X is owned/championed by Y | type_ref |
| depends_on | X requires Y | import |
| fixed_by | X was resolved by Y | call |
| consolidated_into | X was merged into Y during consolidation | import |
| relates_to | General association between X and Y | call |
| extends | X builds on or adds detail to Y | import |
| implements | X is a concrete realization of Y | import |
| requires | X operationally depends on Y (tool, service) | import |

# Consolidation Rules

| Transition | Trigger | Action |
|-----------|---------|--------|
| working -> episodes | Entry age > 24h | Group by tag overlap > 0.3, summarize |
| episodes -> knowledge | access_count >= 3 across 3+ sessions | Promote, confidence +0.2 |
| knowledge -> procedures | 5+ related entries with shared applies_to | Extract workflow |
| any -> .archive | confidence < 0.1 | Move to .archive/ |
| .archive -> delete | age > 90 days AND confidence < 0.05 | Permanent removal |

# Source Provenance

| Value | Meaning |
|-------|---------|
| written | Authored by a human or agent (default when field absent) |
| inferred | Generated by memory.infer from structural analysis — may be outdated after major refactors |
| extracted | Derived directly from index data (reserved for future use) |

Lint flags `inferred` entries older than 30 days as candidates for re-inference.
